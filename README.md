# 公牛旗舰店进销存后台

一个轻量版管家婆风格的进销存后台，用于管理货品信息与出入库记录。

## 功能
- 货品资料管理（新增、编辑、删除）
- 出入库流水登记（自动更新库存）
- 库存总览与按日/周/月统计

## 环境要求
- PHP 8.0+
- MySQL 5.7+ / 8.0+

## 快速开始
1. 初始化数据库：
   ```sql
   source schema.sql;
   ```
2. 配置数据库连接（可使用环境变量）：
   - `DB_HOST`（默认 `127.0.0.1`）
   - `DB_NAME`（默认 `bull_store`）
   - `DB_USER`（默认 `root`）
   - `DB_PASS`

3. 启动 PHP 内置服务器：
   ```bash
   php -S 0.0.0.0:8000
   ```
4. 浏览器访问 `http://localhost:8000`。

## 说明
- 初次启动请先导入 `schema.sql`，确保表结构正确。
- 出入库记录会自动维护货品库存，并支持按日、周、月查看统计数据。
